## Not bugs: deployment, cost or hardening

| ID  | Finding                                                         | Why it's not a bug                                                                                                                                                                                                              | If you act on it                                                                                                                                                                                                               |
| --- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| H1  | Production mode is opt-in; `pnpm start` runs in dev mode        | Matches the specs: `llm-playground` mounts the playground when `dev.playground` is on and `NODE_ENV` isn't `production`. It's a real deployment risk, though: forgetting `NODE_ENV` exposes an open LLM proxy.                  | Highest priority before any deployment. Set `NODE_ENV=production` in `start` and default `dev.playground` to `false` with a dev override. This changes the `app-config`/`llm-playground` behavior, so it needs its own change. |
| H2  | Anonymous users can trigger unlimited paid LLM calls            | No spec requires a cost cap. It's a missing feature, not broken code.                                                                                                                                                           | A new capability: a global LLM concurrency cap, a per-player game cap and a spend budget. Needs product decisions on the limits.                                                                                               |
| M1  | Every cookieless request inserts a `players` row                | `player-session` requires every request without a cookie to get a new player, so the code matches. Narrow deviation: the middleware also runs for non-`/api` paths (e.g. `/robots.txt`), and the spec says "every API request". | Cheap step: mount the player session (and CSRF) under `/api` only. Full fix: lazy player creation plus pruning, which changes the `player-session` spec.                                                                       |
| M3  | Turns have no deadline and keep running after the client leaves | No spec requires a turn deadline. Per-call timeouts and retries are configured.                                                                                                                                                 | A new requirement: a per-turn `AbortSignal` passed through the providers. A cross-cutting change.                                                                                                                              |
| M4  | `trust proxy: false` with an in-memory rate limiter             | A correct default for a single instance with no proxy. Only wrong behind a load balancer.                                                                                                                                       | Set `trustProxy` per deployment and add a shared store when scaling out.                                                                                                                                                       |
| L2  | Prompt delimiter tags aren't escaped                            | Hardening. Code makes every decision and `NumberConsistencyChecker` guards the numbers, so breaking out of the tags can't change outcomes.                                                                                      | Escape `<`/`>` in player text before wrapping. Low effort.                                                                                                                                                                     |
| L5  | Public health endpoint reports provider status                  | Matches the API's health spec; it only reveals whether providers are reachable.                                                                                                                                                 | Return only `status` in production.                                                                                                                                                                                            |
| L12 | Client CSRF flag has to be set by hand to match the server      | Deliberate: commit `666abf4` made CSRF opt-in on both sides.                                                                                                                                                                    | Always construct the client with `csrf: true` (a 404 from the token endpoint already means "off"), and enable CSRF in production.                                                                                              |
| L13 | Inline script in `index.html` will need a CSP hash              | No CSP exists yet, so nothing breaks today.                                                                                                                                                                                     | Handle it when a CSP is added for the SPA host.                                                                                                                                                                                |

## Not bugs: game design (your call)

| ID  | Finding                                                       | Notes                                                                                                                                                                                                                                                                                                                                                                                                                             |
| --- | ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M2  | Free text can end the game irreversibly on a model misreading | The `game-engine` spec states it: "A confident `accept` intent is a player accept, and a confident `decline` intent is a player decline." The risk is real ("I can't accept 30%…" misread as accept). The options: keep it, raise the confidence threshold for game-ending intents, or answer with a `clarify` turn that offers explicit Accept/Walk away buttons. This changes behavior in the spec, so it needs its own change. |
| L4  | Decision logs from failed turns duplicate turn numbers        | The `investor-brain` spec requires every call to be logged, failures included, and the engine's doc comment says so. The insights panel shows these as duplicates. Fix in the display (tag rows with an attempt id and hide uncommitted ones) if the duplicates bother you.                                                                                                                                                       |
| L6  | Insights reveal the investor's live judgments during play     | The `game-api` spec serves insights for any game the player owns. If that's meant as a teaching aid, keep it; otherwise, serve insights only for finished games.                                                                                                                                                                                                                                                                  |
